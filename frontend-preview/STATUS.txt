Custom call controls implementation:
- Vendor-supported path: https://www.cometchat.com/docs/calls/javascript/custom-control-panel
- call-controls.mjs and call-controls.css implement a Ukrainian control bar using
  documented mute/unmute, pause/resume, screen share and leaveSession methods.
- No initiation, credentials, recording or endSessionForAll capability exposed.
- Media and leave state follows SDK events, with timeout/failure feedback.
- Connection loss disables controls; host must remount from fresh verified state.
- This is NOT wired into chat.tsx yet. Session lifecycle and real device behavior
  remain unverified. Hiding the default control panel does NOT localize every
  vendor overlay, such as network/idle/permission screens or video menus.
- Offline tests only: fake SDK methods, no call or permission prompts triggered.
